# e-reading v0.2.0

Android 13 / BOOX Go 7 開發預覽。書架右上角「＋」可選本機書檔與 Android 選檔器提供的 Google 雲端硬碟來源。可選一本直接開書，或多選加入書架。

- TXT 轉成 EPUB 後閱讀。EPUB、PDF、CBZ 可開啟，並保留位置與書籤。
- 無數位版權保護的 MOBI 以 libmobi 轉成 EPUB，包含常見的 MOBI／KF8 文字與圖檔。固定版面複製本與受保護的檔案不在支援範圍。
- 流式正文可切換繁簡，字形轉換使用 OpenCC 字典。Google ML Kit 英文、日文翻譯需要先在 Wi-Fi 下載模型。
- 閱讀頁點中央開工具列。語音翻頁預設關閉，每次開啟 App 都從關閉開始；在閱讀頁按「語音」開啟後說「下一頁」或「上一頁」。離線語音模型為 Vosk 小型中文 0.22，第一次開啟語音時下載（約 42 MB）。
- 閱讀方式可選「翻頁」或「滾動」（閱讀頁點中央 →「Aa」或「自動」）。滾動模式由上往下連續閱讀，可手指拖動，也可點左右兩側或按翻頁鍵一次捲一屏（保留上一屏最後一行）。章尾再往下翻一次進入下一章。每本書各自記住。
- 「自動」：設定秒數（3～120 秒）後自動翻頁；滾動模式可選「一次一屏」或「連續滾動」（秒數為捲完一屏的時間）。開啟工具列、翻頁中或朗讀中會暫停，手動翻頁會重新計時，到書末自動停止。
- 「朗讀」：使用系統的文字轉語音引擎，App 不內附語音，安裝檔不會變大。沒有引擎或中文語音時，App 會引導到系統下載（只需一次，之後可離線）。朗讀會跟著翻頁或捲動，讀完一章接下一章；手動翻頁後從新位置讀起。語速在「Aa」→「朗讀語速」。App 進背景或鎖屏時朗讀停止。
- 頁尾右側顯示正在執行的項目（朗讀中・自動・語音），點一下依序停止。
- Google Drive 入口取決於 Go 7 選檔器。若沒有提供，先在 Drive 下載後從「下載」選檔。

## 下載安裝

在 BOOX Go 7 用瀏覽器開啟 https://github.com/lcfeng1212/e-reading/releases/latest/download/e-reading.apk ，下載完成後點檔案即可安裝。第一次安裝需要允許瀏覽器「安裝不明應用程式」。main 每次更新都會自動換成最新版。

## 編譯

[GitHub Actions](https://github.com/lcfeng1212/e-reading/actions/workflows/android.yml) 會安裝 Android SDK、取得離線模型與繁簡字典、編譯 APK。到成功的執行紀錄下載 `e-reading-v0.2.0`，解壓後安裝 `e-reading-v0.2.0.apk`。APK 為開發測試版。

## MOBI 元件

[libmobi v0.12 原始碼與授權](https://github.com/bfabiszewski/libmobi/tree/v0.12)按 LGPL 3.0 或更新版本使用。編譯工作流程取得該原始碼、關閉加密功能並動態連結。APK 內附上游授權。可替換 `vendor/libmobi` 中的來源後以相同流程重建。

## Go 7 實機驗收

實體鍵碼、Drive 選檔、TXT 轉檔速度、EPUB 版型與續讀、MOBI 樣本、語音誤觸／延遲／耗電、離線翻譯品質都需要實機驗證。鎖屏後測語音是否停止，再回閱讀頁測恢復。滾動模式需實測電子紙殘影、拖動與連續滾動的流暢度；朗讀需實測 Go 7 有無中文引擎、跟頁是否準確，以及語音翻頁是否被朗讀聲誤觸。

流式書籍支援全書搜尋。有文字層的 PDF 可翻本頁或擷取後選取文字。替換書檔時可保留上次閱讀位置，跨版次定位需要實機驗證。掃描 PDF 或漫畫的文字辨識留待後續。
